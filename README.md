> להכפיל את סכום התשלום באחוז שמתאים למספר התשלומים המבוקש,
> ולעגל את התוצאה כלפי מעלה למספר עגול בעשרות שקלים.

```
תוספת = ceil( סכום × אחוז / 10 ) × 10
```

של האקסל בלבד. עמודות הדוגמה שבו אינן נתון, והן שימשו רק לאימות
שעמודה B נקראה נכון.

## החלטות שנגזרו מהכלל, ולא מהמצאה

**חשבון שלמים בלבד.** הסכום מומר לאגורות והאחוז שמור כמאיות האחוז
(‏`2250` = 2.250%), ולכן שתי המכפלות שלמות.
‏`Math.ceil` על מכפלה בנקודה צפה שנופלת בדיוק על עשרת עלול לקפוץ עשרת שלמה
בגלל שארית של 1e-15, בלי שגיאה ובלי רמז. נמדד על 10.5 מיליון צירופים:
היום אין פער בין שתי השיטות, והשלמים מוציאים את השאלה מהתמונה.

**האחוז שמוצג אינו האחוז שבטבלה.** הקובייה הרביעית היא
`התוספת חלקי הסכום`, כלומר מה שנוסף בפועל אחרי העיגול. על 4,000 ש"ח
ב-12 תשלומים הטבלה אומרת 3.782% והמסך מראה **4.00%**, כי התוספת
עוגלה מ-151.28 ל-160.

**השדות הם `type="text"` ולא `type="number"`.** ‏`type="number"` בולע תו
פסול ומחזיר מחרוזת ריקה, ואז אי אפשר להבחין בין "הוקלדה אות" לבין
"השדה ריק", ולכן אי אפשר להציג את ההודעה הנכונה.

**הלוגו מוטמע בקובץ ולא מקושר.** קישור חיצוני נחסם בכל הקשר שמגביל
מקורות, ושובר את הדף בפתיחה מהדיסק בלי אינטרנט. ‏`assets/` מוחרג מגיט,
כי גיט אינו דוחס בינאריים והמשקל נשאר בהיסטוריה לנצח:

```bash
node embed-logo.mjs           # מושך מהחנות ומטמיע. אידמפוטנטי
node embed-logo.mjs --local   # מטמיע מ-assets/logo.png שכבר קיים
```

יש בו שער שמפיל את הריצה על PNG בלי ערוץ אלפא, כי לוגו עם רקע לבן אטום
נראה כמלבן על הדף וזה מתגלה רק בעין.
